# GPB Reviewer

Дашборд для анализа отзывов российских банков с интеграцией ML API для ЛЦТ Хакатона.

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- Flask
- pandas, numpy, openpyxl, requests

### Установка и запуск

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/gpb-reviewer.git
   cd gpb-reviewer
   ```

2. **Установить зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустить сервер:**
   ```bash
   python app.py
   ```

4. **Открыть дашборд:**
   ```
   http://localhost:5000
   ```

## 📊 Возможности

- **Анализ отзывов** - просмотр 250+ отзывов Газпромбанка с фильтрацией по продуктам
- **Визуализация данных** - интерактивные графики трендов и объемов
- **Период фильтрация** - выбор периода: месяц, 3 месяца, год, или кастомный диапазон
- **ML API интеграция** - готовые эндпоинты для подключения модели машинного обучения

## 🔗 API Эндпоинты

### Для ML-интеграции:
- `POST /api/analyze` - анализ текстов (см. ML_API_CONTRACT.md)
- `GET /api/stats` - получение статистики
- `GET /health` - проверка работоспособности

### Для фронтенда:
- `GET /` - главная страница дашборда
- `GET /reviews` - страница просмотра отзывов
- `GET /products` - страница продуктов

## 🤖 ML Интеграция

Подробная документация по интеграции с ML моделью находится в [ML_API_CONTRACT.md](./ML_API_CONTRACT.md).

### Основные принципы:
- **Входной формат:** JSON с массивом отзывов (~250 штук)
- **Выходной формат:** JSON с темами и тональностями
- **Время ответа:** до 3 минут
- **Обработка ошибок:** fallback на `none`/`прочее`/`false`
